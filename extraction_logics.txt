My strongest recommendation

Don't use the LLM to detect objects. Your OpenCV and vector pipeline are already better suited for that. Use the LLM where it excels: reasoning about ambiguous cases.

I'd make the system hierarchical:

Deterministic geometry (your existing code) handles ~90% of the drawing.
Confidence engine flags uncertain detections.
Groq LLM resolves only those uncertain cases using the surrounding structural context.
Graph verification performs a final consistency check (e.g., every beam should connect to valid structural elements, labels should match expected member types).

That architecture is scalable, cost-effective on the Groq free tier, and capable of reaching the production-level accuracy you're aiming for.
